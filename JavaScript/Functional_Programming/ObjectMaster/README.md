# Object Master

## Description

This assignment practices using JavaScript array methods to retrieve and transform data from an immutable Pokémon array.

The solutions use `filter()`, `map()`, and `length` to answer different questions about the Pokémon data.

## Topics

- `filter()`
- `map()`
- Array methods
- Arrow functions
- Objects
- Object.freeze()

## Files

- `objectMaster.js`

## How to Run

```bash
node objectMaster.js
```

## Tasks Completed

- Find Pokémon whose ID is divisible by 3.
- Find all Fire-type Pokémon.
- Find Pokémon with more than one type.
- Get the names of all Pokémon.
- Get the names of Pokémon with an ID greater than 99.
- Get the names of Pokémon whose only type is Poison.
- Get the first type of Pokémon whose second type is Flying.
- Count the number of Normal-type Pokémon.
