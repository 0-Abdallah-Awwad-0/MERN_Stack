# Ninja & Sensei

## Description
This assignment demonstrates Object-Oriented Programming in JavaScript using classes and inheritance.

## Topics
- Classes
- Constructors
- Methods
- Inheritance
- extends
- super

## Features
- Create Ninja objects
- Create Sensei objects
- Display statistics
- Increase health using `drinkSake()`
- Demonstrate inheritance with `speakWisdom()`

## Files
- `Ninja.js`

## How to Run

```bash
node Ninja.js
```
