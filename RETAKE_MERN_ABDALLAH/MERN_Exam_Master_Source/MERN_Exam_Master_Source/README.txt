MERN EXAM MASTER SOURCE

Purpose:
Use this as a copy-and-edit source during the MERN retake.
It follows the same simple course-level patterns used in the Member Manager and Car Manager practice projects.

RUN

Server CMD:
cd server
npm install
npm run dev

Client CMD:
cd client
npm install
npm run dev

Open:
http://localhost:8080

Server:
http://localhost:8000
