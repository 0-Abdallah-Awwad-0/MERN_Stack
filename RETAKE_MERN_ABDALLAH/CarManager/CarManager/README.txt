CAR MANAGER - MERN EXAM PRACTICE

RUN
1. Open CMD in CarManager\server
2. npm install
3. npm run dev
4. Open another CMD in CarManager\client
5. npm install
6. npm run dev
7. Open the Vite URL shown in CMD, normally http://localhost:5173

FEATURES
- List cars
- Empty state with Add Car
- Create car
- Backend validations
- Currency: USD, EUR, NIS
- Transmission: Manual, Automatic
- Details page
- Edit with auto-filled values
- Reusable delete button
- Delete from list and details
- Material UI design
