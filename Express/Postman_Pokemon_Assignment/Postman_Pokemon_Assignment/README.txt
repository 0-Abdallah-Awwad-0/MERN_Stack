POSTMAN + POKEMON ASSIGNMENT

Included files:
- pokemon_requests.txt: submission-ready list of five GET requests.
- Pokemon_Postman_Collection.json: import this directly into Postman.

How to use:
1. Open Postman.
2. Click Import.
3. Select Pokemon_Postman_Collection.json.
4. Open the imported collection.
5. Click Send on each request.

You can submit pokemon_requests.txt, or submit this ZIP if ZIP files are accepted.
