# MongoDB Students Assignment

## Overview

This assignment practices MongoDB fundamentals using a database named `my_first_db` and a collection named `students`.

Each student is stored as a MongoDB document.

## Document Structure

```javascript
{
  name: "Student Name",
  home_state: "State",
  lucky_number: 7,
  birthday: {
    month: 1,
    day: 1,
    year: 2000
  }
}
