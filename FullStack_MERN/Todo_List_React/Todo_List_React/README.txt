How to run:
1. Extract the folder.
2. Double-click START_PROJECT.cmd.
3. Wait for npm install to finish.
4. The browser should open at http://localhost:5173

Features:
- Add tasks
- Delete tasks
- Toggle completed status with a checkbox
- Completed tasks use strikethrough text
- Uses map and filter
- Updates state without mutating the existing array or task objects
- Saves tasks in localStorage so they remain after refresh
- Uses Material UI
